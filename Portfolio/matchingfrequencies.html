Matching Frequencies

Interactive experience to complement the videomaping animation for the event.

Interactive Experience

Matching Frequencies is an interactive experience where the user is able to use their body and manipulate the radio frequencies to match them and make the carnation flower grow. It was created to complement the videomaping animation for the event. In this interactive experience the user can get an introduction to the concept of the videomaping by trying to match the frequencies.

The experience was created using a python script that allowed us to use a webcam to track the user's body. The data exctrated in real time was placed in Unity and used to allow the user to interact with the experience.
